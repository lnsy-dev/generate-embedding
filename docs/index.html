◈ Live embedding

The element below watches its own text. Edit it — whenever you pause typing for 300 ms it re-embeds and publishes a 384-dimensional vector as its vector attribute and an EMBEDDING-RESULT event. Inference runs in a web worker with the all-MiniLM-L6-v2 model, so the page never blocks.

∠ Cosine similarity

Embeddings are points in 384-dimensional space. Sentences with similar meaning point in the same direction. Edit either sentence and the score updates.

A kitten sleeps in the sunshine.

⌕ Semantic search

Every sentence below embeds itself into the same shared space. The query is embedded on demand with window.embeddings.embedTexts() and ranked against the corpus by cosine similarity — no keyword matching involved.

  • The stock market closed lower today.
  • How do I bake sourdough bread?

⚑ How this page is deployed

This demo is built by npm run build:docs into docs/ and served by GitHub Pages as plain static files — fully self-hosted. Every request the page makes stays on the same origin, so CORS can never interfere and nothing is fetched from a third-party CDN or the Hugging Face hub at runtime. The committed artifacts are:

  • main.min.js — the bundle that registers <generate-embedding> and injects its styles
  • generate-embedding-worker.js — the self-contained embedding worker (Transformers.js + ONNX Runtime inlined)
  • models/ — the all-MiniLM-L6-v2 weights (q8 for the WASM backend, fp16 for WebGPU)
  • ort/ — the ONNX Runtime wasm binaries

All four are loaded with relative URLs so the page works from a project sub-path (example.com/repo/):

AttributeValue used hereSource
worker-url ./generate-embedding-worker.js same origin, relative
model-path ./models/ same origin — committed model weights (q8 + fp16)
ort-path ./ort/ same origin — committed ONNX Runtime wasm binaries

The assets are produced by the package's postinstall download (models/ and ort/ at the repo root) and copied into docs/ by npm run build:docs. If you host the demo somewhere that binary assets are awkward, the component still works without them — it then falls back to the Hugging Face hub and a CDN — but self-hosting keeps the demo fast and free of cross-origin requests.

The same three attributes work in any host page — see the README for the full tutorial and programmatic API (window.embeddings).
