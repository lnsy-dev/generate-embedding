generate-embedding

Turn any text on a web page into a 384-dimensional sentence embedding — locally, in the browser, with no API key.

<generate-embedding> is a vanilla-JS custom element that watches its own text, sends it to a dedicated web worker, and emits a sentence embedding using the lightweight all-MiniLM-L6-v2 model (via Transformers.js). It prefers WebGPU when available and falls back to WASM.

Quick start

git clone https://github.com/lnsy-dev/generate-embedding.git
cd generate-embedding
npm install
npm start

Then open http://localhost:3000. The first npm install downloads the model weights (~68 MB) and ONNX Runtime wasm binaries.

Step 1 — Embed editable text

The component watches innerText. Edit the sentence below and pause typing; a 384-dim vector is emitted after the debounce interval.

The quick brown fox jumps over the lazy dog. Waiting for embedding… 
<generate-embedding contenteditable="true">
  The quick brown fox jumps over the lazy dog.
</generate-embedding>

el.addEventListener('EMBEDDING-RESULT', (event) => {
  console.log(event.detail.vector);   // number[384]
  console.log(event.detail.duration); // ms
});

Step 2 — Compare sentences with cosine similarity

Embeddings turn sentences into points in space. Two vectors that point in the same direction are semantically similar. The cosine similarity score ranges from -1 to 1; for normalized sentence embeddings it is effectively 0 (unrelated) to 1 (very similar).

A cat naps in the sun.
A kitten sleeps in the sunshine.

Step 3 — Tiny semantic search engine

Because every embedding lives in the same 384-dimensional space, you can find the sentence closest to a query by comparing vectors.

  • A cat naps in the sun.
  • The stock market closed lower today.
  • How do I bake sourdough bread?

    Step 4 — Persist embeddings in markup

    Every successful embed writes generated and vector attributes to the element. If you save that markup and reload it, the component restores the vector immediately without starting the worker. 

    <generate-embedding generated vector="[0.0123,0.0456,...]">
  A cat naps in the sun.
</generate-embedding>

    Edit the text and the marker is cleared; a fresh embedding is computed on the next debounce.

    Step 5 — Configuration

    AttributeDefaultPurpose

    ort-path/ort/Base URL for ONNX Runtime wasm files.

    Step 6 — Tests and production build

    # Unit tests
npm run test:unit

# E2E tests (first run needs Chromium)
npx playwright install chromium
npm test

# Production build
npm run build

    The build emits dist/main.min.js, dist/generate-embedding-worker.js, and copies models/ and ort/ if they were downloaded. Serve dist/ from any static host.
